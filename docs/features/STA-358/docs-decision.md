# Docs decision: STA-358

No help-center change. The four questions:
- **User-visible behaviour changed?** Only on the public marketing site (crawler-facing HTML, titles, redirects, prices rendered on the server). Nothing changed in the business dashboard or the scanner app.
- **New setting or option?** No.
- **Error message or copy changed?** Marketing and pricing copy only. The help center (`content/docs/en/team/*`) makes none of the corrected claims: offline scanning, scheduled card styles, "no card required", open rates.
- **Pricing or tier gating changed?** No gating changed. The marketing copy now matches the existing gates (scheduled card styles and geofencing are "coming soon" on Pro).
